# Fulfillment Match

이커머스 화주와 3PL 업체를 연결하는 **B2B 영업 매칭 서비스**입니다.

화주는 자신의 물류 운영 조건을 등록하고,  
3PL 업체는 서비스 가능 조건에 맞는 화주 요청을 확인한 뒤 견적을 제출할 수 있습니다.

현재는 Spring Boot와 Thymeleaf 기반으로 MVP를 구현하고 있으며,  
향후 REST API + React 구조로 확장할 예정입니다.

---

## 프로젝트 배경

이 프로젝트는 **B2B 영업 과정에서 공급사와 잠재 고객사를 더 효율적으로 연결할 수 없을까**라는 아이디어에서 시작했습니다.

B2B 영업은 일반 소비자 대상 서비스와 달리 거래 조건이 복잡하고, 공급사 입장에서는 자사의 서비스 조건과 맞는 고객사를 찾는 과정에 많은 탐색과 영업 활동이 필요합니다.

이를 단순한 업체 목록이나 광고 형태가 아니라, 양측의 조건을 구조화하여 적합도가 높은 거래 상대를 연결하는 **B2B 영업 매칭 플랫폼** 형태로 구현해보고자 했습니다.

첫 적용 도메인으로는 제가 경험해온 이커머스 물류와 연관성이 높고, 화주와 3PL 업체 간에 취급 상품, 물동량, 운영 지역, 보관 방식, 부가 작업 등 다양한 거래 조건이 존재하는 3PL 시장을 선택했습니다.

### 문제 가설

현재 단계에서는 실제 화주 및 3PL 업체를 대상으로 사용자 인터뷰나 시장 검증을 진행하지 않았으며, 아래 내용은 서비스 기획을 위한 가설입니다.

- 3PL 업체는 자사의 운영 조건과 적합한 신규 화주를 지속적으로 발굴해야 한다.
- 화주 역시 자신의 물류 조건에 적합한 3PL 업체를 탐색하고 비교하는 과정이 필요하다.
- 양측의 조건이 표준화되어 있지 않으면 초기 영업 과정에서 불필요한 문의와 탐색 비용이 발생할 수 있다.
- 거래 조건을 구조화하고 사전에 적합도를 계산하면 영업 대상 선정의 효율을 높일 수 있다.

### 서비스 가설

화주가 필요로 하는 물류 조건과 3PL 업체가 제공할 수 있는 운영 조건을 데이터로 구조화하여 비교하면, 양측이 무작위로 업체를 탐색하거나 영업하는 것보다 적합한 거래 상대를 빠르게 찾는 데 도움을 줄 수 있다고 가정했습니다.

### MVP 방향

초기 MVP에서는 계약, 정산, CRM 등 전체 B2B 영업 프로세스를 구현하기보다 **조건 기반 매칭이 서비스의 핵심 기능으로 동작할 수 있는지 구현해보는 것**에 집중했습니다.

주요 흐름은 다음과 같습니다.

`화주 물류 조건 등록 → 3PL 운영 조건 비교 → 매칭 점수 계산 → 적합 업체 추천 → 견적 작성`

향후에는 실제 화주 및 3PL 업체를 대상으로 영업 방식, 업체 선정 기준, 견적 요청 과정 등을 조사하여 가설을 검증하고, RFQ·견적 비교·영업 리드 관리 기능까지 확장하는 것을 고려하고 있습니다.

## 현재 구현 범위

현재는 Thymeleaf 기반 MVP로 다음 기능을 구현하고 있습니다.

- 화주 물류 요청 관리
- 3PL 업체 관리
- 견적 관리
- 조건 기반 매칭

서비스 전체 B2B 영업 프로세스를 구현하기보다 초기 단계에서는 **화주와 3PL 업체의 조건을 구조화하고 적합한 거래 상대를 추천하는 핵심 로직**에 집중했습니다.

## 주요 기능

### Shipping Request

- 화주 물류 요청 등록
- 요청 목록 / 상세 조회
- 요청 수정 / 삭제
- DTO 기반 Validation

### Fulfillment Company

- 3PL 업체 등록
- 업체 목록 / 상세 조회
- 업체 수정 / 삭제
- 서비스 가능 조건 관리

### Quote

- 화주 요청과 3PL 업체를 연결한 견적 등록
- 견적 목록 / 상세 조회
- 견적 수정 / 삭제
- JPA 연관관계를 이용한 요청 / 업체 연결

### Matching

화주의 요청 조건과 3PL 업체의 서비스 가능 조건을 비교하여 조건에 맞는 업체를 추천합니다.

현재 비교 조건:

- 서비스 가능 지역
- 냉장 / 냉동 가능 여부
- 반품 검수 가능 여부
- 특수 포장 가능 여부

조건을 만족한 업체는 매칭 점수를 계산하여 높은 점수순으로 정렬합니다.

매칭 결과에서 바로 견적 작성 화면으로 이동할 수 있으며, 화주 요청과 3PL 업체가 자동 선택됩니다.
